
# 💜 HybriOS – Features

## 🐧 Linux Foundation
HybriOS is built on a Linux-based foundation, focusing on flexibility and lightweight performance.

## 🖥️ XFCE Desktop
HybriOS uses XFCE to provide a familiar and customizable desktop experience.

## 🎨 Custom Appearance
- Custom HybriOS wallpaper
- Custom desktop themes
- Customized desktop panel
- Purple and blue visual identity

## 🪟 Windows Application Compatibility
HybriOS aims to support Windows applications through compatibility tools where supported. Not every application is guaranteed to work.

## ⚡ Project Goals
- Lightweight desktop experience
- Easy-to-use interface
- Customization
- Linux flexibility

## 🚧 Under Development
HybriOS is experimental. Features may change as development continues.
